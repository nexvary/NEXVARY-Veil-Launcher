# Leakage audit matrix — 0.2.0 alpha

This is a scoped source and automated-test audit, not a physical-device certification. Veil concealment does not change Android package identity. PRIVATE_SPACE requires Android 15+, default HOME authorization and an existing private user; primary-profile copies receive no isolation benefit.

Verified security/lifecycle baseline: [`d0ae9ab`](https://github.com/nexvary/NEXVARY-Veil-Launcher/commit/d0ae9abbb5adf208fb03fa091a436a3de0847d95), [GitHub Actions run 37264421416](https://github.com/nexvary/NEXVARY-Veil-Launcher/actions/runs/37264421416), 2026-10-05. Unit tests: 13 passed. Instrumentation: API 34: 12 passed, 1 unsupported Private Space test skipped; API 35: 13 passed, none skipped; API 36: 13 passed, none skipped. Unit/lint/build and all three emulator jobs succeeded. Actual authenticated process termination, emulator reboot and PIN reauthentication with retained configuration pass on all three APIs. Arabic RTL, substituted alias/icon with a real-target launch and saved UI proof are verified. Alpha03 UI changes must earn their own green run.
